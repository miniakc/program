# EMS QUIZ Windows 0.4.1

Windows 10/11 x64용 독립 설치 프로그램입니다. 사용자의 PC에는 Python, Office, OCR 엔진을 별도로 설치할 필요가 없습니다.

## 사용 순서

1. **자료 관리**에서 PDF를 등록합니다. 텍스트를 추출하고 필요한 페이지는 내장 한국어·영어 OCR로 인식합니다. 작업명·페이지 진행률·경과 시간·중단 상태를 하단에 표시합니다.
2. 본문을 확인한 뒤 **MD·이미지 ZIP 저장**을 누릅니다. 챕터는 선택 사항입니다. MD만 저장하면 같은 위치의 `images` 폴더에 그림도 저장합니다.
3. ZIP을 압축 해제합니다. GPT에 `교재.md`, `출제요청.txt`, **필요한 실제 그림 파일**을 함께 첨부하고 출제 범위와 문항 수를 지정합니다. MD의 링크만으로 이미지가 전달되지는 않습니다.
4. GPT에서 UTF-8 JSON 파일을 다운로드합니다. 프로그램의 **JSON 가져오기**로 등록한 뒤 **선택 문제 바로 풀기**를 누릅니다. 검토 완료 여부와 관계없이 풀 수 있습니다.
5. 선택 문제(미선택 시 검색 결과 전체)를 JSON 또는 **Excel .xlsx**로 저장합니다. Excel에는 지문·선택지·정답·해설·출처·페이지·이미지 파일명을 기록합니다. 실제 그림은 별도 `문제 이미지` 시트에 삽입합니다. 그림 원본은 교재 ZIP에도 보관합니다.

각 문제의 오른쪽 위에서 **10초**가 자동으로 줄어듭니다. 시간 종료 시 자동 정답 공개/이동은 하지 않습니다. Space로 정답·해설, 방향키로 이전·다음, 버튼으로 10초 재시작이 가능합니다. 정답을 보거나 다른 화면으로 이동하면 타이머가 멈춥니다. 문항 수(전체/10/20/30/50)와 무작위 순서를 선택할 수 있습니다.

## 이미지 문제

PDF의 개별 래스터 이미지와 전체 페이지 미리보기를 별도 PNG로 저장합니다. 벡터 도형·복잡한 그림·스캔은 전체 페이지에 보존되며 개별 그림 영역을 의미에 따라 자동으로 잘라내지는 않습니다. 캡션·정답이 함께 포함되는지 원본을 확인하세요.

MD에 페이지와 이미지 ID(파일명)를 기록하고 JSON의 `images`에 그 ID를 그대로 사용합니다. 같은 PC는 JSON만 가져오면 연결됩니다. 다른 PC는 **사용안내 · 이미지 → 교재 이미지 ZIP 가져오기**에서 원래 교재 ZIP을 먼저 등록하세요. 이미지를 찾지 못하면 파일명을 표시합니다. 문제 수정에서 별도 PNG/JPG를 첨부할 수도 있습니다. 퀴즈 그림은 클릭하면 Windows 기본 이미지 앱에서 원본 크기로 열립니다.

## JSON 형식

```json
{"questions":[
  {"type":"객관식","topic":"주제","concept":"학습목표","stem":"문제","options":["가","나","다","라"],"correct":0,"explanation":"해설","source":"교재명","page":1,"quote":"원문 인용","images":["교재MD에_기록된_이미지ID.png"]},
  {"type":"OX","concept":"목표","stem":"설명은 옳다.","answer":"O","explanation":"근거","images":[]},
  {"type":"단답형","concept":"목표","stem":"명칭은?","answer":"정답","explanation":"근거","images":[]}
]}
```

객관식 correct는 **0~3**입니다. `images`는 경로 없이 ASCII 파일명만 사용합니다. 기존 웹 버전의 OX/단답형 `showStem`/`showAnswer`도 읽습니다. 중복 지문은 재등록하지 않습니다. 문제 생성·자료 전송은 사용자가 GPT에서 수행하며 이 앱은 API 키를 요청하지 않습니다.

## 자료와 백업

기존 버전과 같은 `%LOCALAPPDATA%\EMSQuiz` 폴더와 DB를 사용합니다. 설치/업데이트/제거 시 사용자 자료는 삭제하지 않습니다. 전체 백업 ZIP에 DB·원본·이미지를 포함합니다. 백업 복원 UI는 제공하지 않으며 원래 사용자 데이터 폴더에 수동 복원할 수 있습니다.

## 빌드

빌드 PC에만 Python 3.12 x64와 Inno Setup 6이 필요합니다. `build-windows.ps1`은 테스트, PyInstaller 번들, 내장 OCR, 번들 실행, 설치 및 Python이 PATH에 없는 환경에서 실행, 제거를 검사합니다. GitHub Actions는 이 과정을 통과한 EXE만 릴리스에 게시합니다.
